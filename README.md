# Modern Transformer architectures
### The main goal of this repo is to understand the modern decoder-only transformer architectures, that have evolved from 2017's Encoder-Decoder model proposed in "Attention is all you Need" paper.

**LitGPT GitHub repo was used for learning the base implementation of modern architectures especially for understanding Grouped Query Attention (GQA), Rotary Positional Encoding (RoPE), GeLU, SWiGLU, decoder-block only model etc.**
